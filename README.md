# ❤️ Heartbeat Sync

Простое расширение для **SillyTavern** с плавающим виджетом-сердцем, анимацией ЭКГ и синхронизацией «пульса» через теги AI.

Виджет появляется сразу после загрузки, можно перетаскивать, работает на ПК и на Android/Termux.

---

## 📦 Установка

1. Открой SillyTavern → **Extensions** → **Install extension**
2. Вставь ссылку: 

https://github.com/CrewwCreww/heartbeatsync

3. Нажми **Install** и перезагрузи страницу

После перезагрузки в правом нижнем углу появится полупрозрачное окошко с сердцем и кнопкой **Activate**.

---

## 🚀 Как пользоваться

1. Открой любой чат с персонажем
2. Нажми **Activate** на виджете
3. В системный промпт или в карточку персонажа добавь инструкцию AI:

В КОНЦЕ каждого своего ответа обязательно добавляй ровно одну строку:
{{HS::SYNC:XX}}
где XX — целое число от 0 до 100 (текущая эмоциональная/физиологическая интенсивность персонажа по отношению к пользователю).
Не объясняй тег. Не ставь его в середине сообщения.

4. Общайся — после каждого ответа бота виджет будет обновлять процент, цвет и скорость пульса.

---

## ✨ Возможности

- Плавающее полупрозрачное сердце (glassmorphism)
- Анимированная линия ЭКГ
- Цвет и частота пульса зависят от score (0–100)
- Перетаскивание пальцем / мышкой
- MutationObserver + события SillyTavern — теги ловятся надёжно
- Без `fetch`, без CORS-проблем, работает на Termux
- Стили инжектятся из JS
